## Project Overview
A MySQL-based Library Management System designed to manage books, borrowers, and book loan records.

## Technologies Used
- MySQL
- SQL
- MySQL Workbench
- Git & GitHub

## Database Tables

1. Books – Stores book details and availability.
2. Borrowers – Stores borrower information.
3. Loans – Tracks book borrowing and return records.

## SQL Concepts Implemented

- Database and table creation
- Primary and Foreign Keys
- INSERT, UPDATE, DELETE
- SELECT and WHERE
- LIKE, IN, BETWEEN
- ORDER BY and LIMIT
- DISTINCT
- Aggregate Functions
- INNER JOIN
- LEFT JOIN
- RIGHT JOIN
